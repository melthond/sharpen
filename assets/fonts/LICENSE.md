# xkcd Script font

`xkcd-script.woff` is the hand-drawn "xkcd Script" font from [ipython/xkcd-font](https://github.com/ipython/xkcd-font), based on Randall Munroe's handwriting. It's the same font the [Star History](https://star-history.com) charts use.
